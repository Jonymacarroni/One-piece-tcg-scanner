\# One Piece TCG Card Scanner



Aplicación web para identificar cartas de One Piece Card Game mediante una fotografía.



El sistema procesará la imagen con OpenCV, utilizará OCR para reconocer el código de la carta y consultará una base de datos para mostrar su información en español.



\## Objetivo



Desarrollar una aplicación web capaz de reconocer cartas de One Piece TCG a partir de imágenes, consultar sus atributos y guardarlas en una colección personal.



\## Funcionalidades principales



\- Subir o capturar una fotografía de una carta.

\- Detectar y recortar la carta.

\- Reconocer su código mediante OCR.

\- Consultar la información de la carta.

\- Mostrar sus atributos en español.

\- Guardar la carta en una colección personal.
